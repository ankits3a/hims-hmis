What the national chains do at each seat, and what this design takes from them Dr Lal PathLabs · Pathkind · Agilus (SRL) · Apollo Diagnostics — from their public process and reference guides
seatreceptioncollectionbenchverificationdelivery
The chains One visit ID per patient per day, printed on the receipt. Barcode minted at registration, not at the bench. Colour-coded tubes with the test list printed on the label. Order of draw is a wall chart. Home-collection kits carry a master barcode for transport. Analysers interfaced both ways (ASTM / HL7): orders go down, results come up. Manual entry only when the interface is down. Auto-validation for normal, in-range results; a doctor authorises everything flagged. Two signatures for some disciplines. Report by WhatsApp and SMS as a password-protected PDF, an app login, or the website with visit ID + OTP. Counter copy on request.
Taken here Token + UHID are the visit ID. The L order number and S tube barcodes are minted on Save, and print at the chair. Order of draw is on the screen, not the wall. One barcode per tube; a scan confirms each. A missed wristband scan forces a named re-check at the bench. Scan-to-identify; serial interface first, printout second, and a typed value outside the absurd envelope needs a second enterer. Every result passes a pathologist today (auto-verification ships with zero rules). Criticals are telephoned at entry, not at signature. Doctor's screen never waits. WhatsApp / SMS / email / counter. The print is held on an unpaid slip; only the billing manager can release it.
