Which order do the counters run in?

This is the only switch in the app that changes where a patient walks. It changes the screens the staff see, what the token slip says, and which counter is allowed to put someone in a queue.

Queue first, bill after IN USE

The appointment counter picks the doctor and issues the token, then the patient pays. The fee can differ by department, by doctor and by visit type — a follow-up inside the window is free.
