## 1. Refutations

### G1 — the alarm ledger

- **F2 (amend, prior)** "cancels ÷ escalations < 20 % over any 7 days" has no source and no floor; at prod's volume (0 escalations) it is 0/0. State the floor (e.g., read only when escalations ≥ 20 in the window) and the source, or replace with the measure the code itself names: the distribution of `queue.escalation_cancelled.withinMs` (:258).
- **F3 (note, prior)** "who reads it: the digest fact sheet (DPIA:11)" — no Digest Writer exists in code; the reader is a person over a query or the desk brief (`kernel/desk/brief.ts`). Say so.

- **F5 (note)** Baseline "prod ≈ 0 (498 events)" — 498 was read before the 12:35 UTC deploy and cannot be re-read by a session; write "~500 at the last reading (09-06, pre-deploy); unmeasured since".
