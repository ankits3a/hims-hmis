## 5. DECIDED and RULINGS

**DECIDED (Indian-corporate-hospital standard; one line each).**
1. Patients see **position**, staff see **minutes with an age**; the predictor is a read model, informational — L1 order is never touched (22c-D DD4; doc 20:26).
2. Pace = per-doctor median of the trailing 30 completed consults, computed on read, `n ≥ 10` else the department constant, which stays as the fallback; the quote is persisted (`wait.quoted`) so it can be scored.
3. The 20-minute rule reads the measured pace once E1-M1 lands; a doctor on leave or with an empty session never wins the comparison (the FD-7 T8 lesson).
4. Delay declaration is one tap by the doctor or PA on the session; it shifts class computation only; the desk tells the clerk today; patients are told by template **once WABA + DLT exist** (R-020; `NOTIFY_PROVIDER` is `console`-only until P4).
5. `slot_minutes_by_type` defaults to the 10-minute ruling for all types; values change only from 30 days of medians, rounded to 5, signed by the OPD head — "dynamic" = set from data, never re-ordered by a model.
6. A longer booking claims consecutive starts under the existing partial unique index; no second arbiter (22c-C DD1's rule kept).
