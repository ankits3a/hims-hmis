## 0. The mission sentence(s) this pillar serves, and the honest reconciliation with the spec

**3a:** *"replace traditional in-house PACS servers with high-speed fibre … transmitting imaging directly to our cloud for instant AI annotation and 3D volumetric analysis across neurology, orthopedics, oncology, and chest trauma"* — *"intracranial hemorrhage mapping, fracture detection, implant positioning, pneumothorax identification"*. **3b:** *"analyse surgeon availability, OT capacity, procedure type, anaesthesia and equipment needs to auto-schedule and continuously rebalance surgical timelines in real time if delays occur"*.

1. **"Eliminate in-house PACS servers" inverts the owner's standing ruling.** spec:24-33 (v4.7, 2026-08-22): *"Hosted on local (on-premises) servers … THIS IS THE END STATE … No managed cloud service becomes load-bearing."* The WAN-down day relies on *"modalities keep acquiring (edge-local DICOM to Orthanc)"* (`00-CROSS-MODULE-CHAOS.md:42`); 18b §7 R1 recommends an on-prem Orthanc (18b:88). **Reconciled goal (D1 — a standing ruling upheld, not a decision):** *"cloud" is the offsite tier and the AI tier, never the acquisition edge* — images land on-prem, replicate to an India-region object store (doc01 O-9 `:578`; R-254 REG:266), and leave only through a governed outbound register. Only the owner can reverse v4.7 (NEW-P3-1 (c)).
2. **"Instant transfer" is procurement plus one measured parameter.** `fibre|bandwidth|Mbps` occur nowhere in the repo; the only number is storage growth (doc01:564). HMIS measures acquisition→viewable (`imaging.study_acquired` → first `imaging.image_viewed`, `modules/radiology/events.ts:66,105`) once images flow; link, redundancy and MWL licences are purchases (18b R2 `:89`).
3. **"AI annotation" is bought, T1 first, T2 forever — and the inference seams have moved.** R-008 (REG:20) reads, in full, *"None in 18a/18b; evaluate CXR-triage/stroke tools only as T1 nudges after PACS is stable; bought never built"* with plan column `18b` — E4 is homed as 18b-iv by that column, and D3 *extends* R-008's T1 default to a T2 field. spec:778 caps clinical actions at T2–T3 permanently. **Measured now:** `kernel/inference/types.ts` exports `SpeechClient` (:49), `InferenceClient` (:83) and `ChoiceClient` (:134); `kernel/inference/openai-compatible.ts` builds an `InferenceClient`; `kernel/copilot/` is 13 files (#239–#252), *"a model that routes but never answers"* (`router.ts` header) — the desk copilot, on production since 09-19/09-20; `modules/opd/triage.ts:26` sends a masked complaint to a cloud model. RM:428 still reads *"No 12a agent runtime"* and `kernel/auth/guards.ts:99-101` still throws *"agents hold no permissions yet"* — so E4's "12a built" gate stands and means **`agent_permissions` + the agent door open**, not the copilot. A machine finding is a worklist hint + a row, never a report sentence (18b D7; `radiology-pacs-go-live.md` §6).
4. **"3D volumetric analysis" has no consumer.** MPR is a viewer capability (OHIF free, 18b:90); volumetric *measurement* is a vendor product's output. ICH and tension pneumothorax are **Red**, unexpected fracture **Orange** (doc01:127); the consuming departments — ED (40), orthopaedics/neurology (no plan), chest trauma (40/67), major OT (48) — sit behind the IPD gate (RM §4). DPIA:20 is design law — *"Class 2 never enters an inference request — any stage, any provider, ever."* The only precedent for Class 2 leaving is §3-A (DPIA:31-33), *"the law's single named exception, pending owner accept/refuse and counsel review"*. **Every byte that leaves — replica, teleradiology, AI processor — needs a second named carve-out on §3-A's terms plus lawful basis and notice (DPIA §4 `:37`)** — the owner's and counsel's act (NEW-LAW-1), never an addendum a lane writes.
