## 0. Position in one paragraph

The only discharge the system can perform today is the mini-OT day-care discharge (Plan 15, migration `0035_mute_vision.sql`, inside production's 56): scores-to-threshold → escort re-verified → ISBAR acknowledged → bay released → bill composed. It has no clearances, no summary, no document, no follow-up task and no consumer of its own event.
