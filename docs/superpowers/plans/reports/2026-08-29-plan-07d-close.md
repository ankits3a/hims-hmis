## 4. Findings

**§2.132 paid for itself on its first use.** The preflight rule written by this session's own token
audit hours earlier (typecheck + lint before the twenty-minute run) caught a §4 architecture
violation in twelve seconds: this task's test imported `../tariff/services` directly, and a module
may import only another module's `index.ts`.

**And it caught the rule's own command being wrong.** `pnpm lint 2>&1 | tail -8 && echo "PREFLIGHT OK"`
printed OK over a FAILING lint, because that is `tail`'s exit status — AGENT-RULES rule 16, inside
the very command written to save a run. It was seen only because the OUTPUT was read rather than the
echo. The preflight now writes to a log and reads `$?`.

**A `toEqual` earned its keep.** `prescriptions.test.ts` asserts the print payload with `toEqual`
rather than `toMatchObject`, and its own docstring says why: "a payload that grew a field nobody
decided to add should fail here." It did. The expectation was updated deliberately, not loosened.

**A second host OOM.** `dmesg` names pid 917231 at 09:00:36 with fail2ban invoking the oom-killer.
Two of this session's eleven verify launches died that way. Both suites passed isolated and both
runs were paid for again rather than the red being explained away.

**`RxPrint` needed a `?? []`.** A browser tab open across a deploy holds a print payload older than
`advisedTests`, and an undefined list must read as "none advised" rather than crash the printable
document — a prescription that will not render is a patient who leaves without their slip. Same
reasoning `auth.tsx` records for `permissions ?? NO_PERMISSIONS`.

## 5. For the close reviewer

1. **The two history readers are the widest PHI reads this application makes.** `chainFor` is one
   function serving both, and it is the single place the gate, the log and the merge chain are
   applied. If it is wrong, both endpoints are wrong the same way.
2. **The advised-test price is a snapshot with no bound on staleness.** It is written when the doctor
   advises and printed unchanged. E-9 rules that the counter reprices — but nothing in the system
   *enforces* that the counter looks, and a slip carrying a six-month-old price is a quotation
   somebody may argue about. Name the transaction where that matters.
3. **Not asserted end to end:** no e2e covers `GET /opd/patients/:id/prescriptions` over HTTP. The
   gate, log and merge chain are proven at the module level (`history.test.ts`) and the ROUTE's
   permission (`opd.consult` rather than `opd.visits.read`) is proven only by reading the decorator.
