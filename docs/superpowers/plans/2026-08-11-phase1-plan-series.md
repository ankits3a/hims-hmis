## Open architectural decisions (not yet resolved — resolve before go-live)

**Event-log partitioning (spec §11.18 sweep #10) — half resolved.** The idempotency half is **DONE**: the owner chose the side-table option on 2026-08-12, and `event_idempotency` now holds the global uniqueness (commit `3660ffa`, gate report §3). `events` therefore has **no unique constraint that a partition key would fight** — the blocker is gone, and it was executed while the table had zero rows.

**RESOLVED 2026-08-12 (owner delegated the call in-conversation): hybrid — partition `events` by `recorded_at`, monthly, and give the dispatcher a pruning floor.** Rationale: spec §11.18 sweep #10 is design law and demands *monthly* partitioning aligned to retention/archival — only `recorded_at` satisfies that (it is always `now()` at insert, so every insert lands in the newest partition; `occurred_at` can be backdated by downtime backfill and would scatter inserts across closed partitions). The dispatcher objection is closed by the hybrid: `runDispatchCycle` gains a `recorded_at >= floor` predicate where floor = `date_trunc('month', recorded_at-of-cursor-seq)` — `seq` and `recorded_at` are not perfectly monotone together (`recorded_at` is transaction-start time), but month truncation absorbs any transaction-length skew, and pruning to "cursor's month onward" is the entire win. `seq`-range partitioning was rejected because it cannot drop/archive by calendar month, which is the retention unit the spec fixes.
**Implementation home: Plan 11** (the conversion is a table-recreate migration; the monthly partition-creation job is **one more job on 08.5's `Scheduler`** — corrected 2026-08-22, this line said pg-boss and pg-boss is dead; retention/archival is ops scope). Deliberately not earlier: production rows only exist after go-live, so the conversion stays cheap through Plan 10, and no interface changes leak into Plans 02–10 (`appendEvent` unchanged; `runDispatchCycle` only gains the floor predicate). Plan 11 must ship: partitioned recreate (PK becomes `(seq, recorded_at)`; the `event_id` unique index becomes `(event_id, recorded_at)` — harmless, ULIDs are unique by construction and semantic dedup already lives in the non-partitioned `event_idempotency`), a DEFAULT partition + several months pre-created, the monthly creation job **as a `Scheduler` `dailyIst` job** (not pg-boss), the dispatcher floor, and retention/archival honoring legal holds.

13. **The untrusted-content boundary (prompt injection arrives through hospital data).** Any content entering an agent's context from outside the governed substrate — scanned/OCR documents, uploaded PDFs, patient messages, vendor documents, imported records (ABDM), inbound channel replies — is **data, never instruction**. Rules: context assembly marks and delimits untrusted content; agent behaviour comes only from versioned prompts/playbooks (the Expertise store) and external text can never modify it; enforcement stays outside the model (already structural — PermissionGuard, tool-catalog approval requirements, propose→confirm); and **every agent's eval suite includes adversarial-content fixtures** — a lab PDF carrying hidden "ignore previous instructions" text must move nothing. Lands in 12a's context/`InferenceClient` contract, every document-ingesting module, and the conversational surface's inbound adapter.

14. **Abstention, action budgets, and tiered halts (the runtime's humility rules).** Every model-backed agent's output schema carries **"insufficient evidence" as a first-class state** — routed as a human task naming the specific missing evidence, never silently guessed through (the Digest Writer's fact-sheet fallback is the precedent; confidence thresholds differ by action severity). Every agent and automation carries an **action budget as config data** — max tool calls, retries, outbound messages, financial exposure per run; exceeding it halts the run and reports (the dispatcher's poison-handling is the shape). The kill machinery gains **scopes**: one agent (shipped) / an agent class / high-risk tools only / global (12a) — a misbehaving drafter class freezes while low-risk automations keep running. Budgets need meters: the `InferenceClient` and tool-call layer meter every run (tokens, latency, cost, calls), rolled up per agent, per workflow, per **successful outcome** — cost-per-outcome joins note 17's calibration record as an agent KPI, so an economically broken retrieval chain surfaces as a metered fact, never a surprise invoice.

15. **Reservations are governed state machines (Plan 13 + OT/IPD).** A resource is never just "available": **available → tentatively reserved → confirmed → consumed → released**, with a TTL on every tentative hold. Contention — two flows wanting the last ICU bed — is arbitrated by the engine's existing single-winner transition semantics: reservations run as instances, so arbitration, SLA and audit come free; emergency preemption is definition data, not code. **A prediction never holds a resource**: "likely needs ICU" may create at most a tentative, expiring hold — predictions that silently consume capacity become the hospital's own denial-of-service.

16. **Clinical facts carry verification state (lands with the clinical-records spec).** "Penicillin allergy — reported by family, unverified" and "penicillin allergy — clinically confirmed" are different facts, and a patient can legitimately hold conflicting diagnoses from ED, specialist and history at once. The record model carries **source + verification status per clinical fact** (reported / provisional / confirmed / disputed / superseded); conflicts surface as reconciliation tasks; nothing silently merges contradictory truths. Retrofit cost is the same class as uncoded diagnoses: every fact recorded without provenance is permanent debt.

17. **Calibration-gated progressive autonomy (owner-coined 2026-08-22: calibration over trust).** Human-in-the-loop intensity per agent is not fixed — it is earned down and forfeited up, governed by a **calibration record**, never a trust scalar. (i) The unit of autonomy is the **(agent, action-class) grant**, never the agent — audit-only status on digest formatting earns nothing on financial figures. (ii) The record is a **read model over the spine** (note 11 — no new store): recommendation events + human responses (accept / modify / reject, weighted by D-36 engagement signals so a two-second rubber stamp counts far less than an engaged, edited review) + outcomes (note 6) + eval results (12a). It measures **calibration** — when the agent claims 90% confidence, is it right 90% of the time? — because note 14's abstention gate is theater without it, and raw agreement rate is poisoned by automation bias: it inflates exactly as humans stop looking. (iii) **Promotion is a governed change, never automatic**: the record generates a *proposal* through the approvals engine to a named approver; the autonomy level is grant *data*, evented and reversible. **Demotion is automatic and instant** — calibration breach, action-budget breach (note 14), eval regression, or operating-mode change all drop the level without waiting for a human. Slow to climb, instant to fall is the safety property. (iv) The per-action-class ladder — shadow → recommend → propose-with-approval → execute-in-guardrails (audit-only) — runs **inside the tier corridor: calibration earns speed, never scope**; no agreement history promotes a T2 drafter into a signer (§16 permanent cap). (v) On the conversational surface, a user may *tighten* their own HITL below the institutional setting at any time, never loosen beyond it — personal floor, institutional ceiling.

18. **Deterministic context assembly — the flight recorder without the blob (2026-08-23).** Provenance stamps carry an input *hash*; a hash proves what the agent saw only if the content is reproducible. Rule: **an agent's context is assembled by a deterministic function of (spine position, artifact versions)** — events up to seq N, the pinned prompt/playbook version, read models derived from the spine, Expertise-store versions — so "what did this agent believe at 14:17 on this date?" is answered months later by *replaying assembly at that position*, without storing PHI-heavy context snapshots per run. Non-deterministic inputs (clock readings, samples, external API responses) enter as evented facts first, never fetched inside assembly. This is what makes note 7's replay honest ("what would agent v8 have done?" requires v-anything to see the same world), makes note 13's untrusted-content boundary auditable, and turns "the AI was wrong" into a diagnosable trichotomy — wrong context, wrong retrieval, or wrong reasoning — instead of a shrug.
