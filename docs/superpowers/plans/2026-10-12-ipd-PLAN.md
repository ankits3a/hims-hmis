Date 2026-10-12 · milestone "IPD core" · Refs #712 · owner said "execute the plan" on 2026-10-12 (decision 0072)

This plan says in what order they are built and how "done" is proved. The specs stay in the owner's context folder

## How "done" works here (three levels)

1. **An epic is done** when every check in its "done means" list passes in CI, the lane is staged, the owner
   walks it on staging against the design board, and it is merged. A check is binary and names its test.
2. **A milestone is done** when all its epics are done AND its exit gate (a real-world rehearsal or live
   measurement, written below) passes and is recorded in §6 with date and evidence.
3. **A goal is done** when its target holds on production for its whole window, read by the query named in §6,
   dated, and shown to the owner. Baselines are measured in the rehearsal (M3), never guessed. The target
   table is recorded in decision 0072.

## 3. Epics with "done means"

Each epic is one lane, one PR series, one migration at most per PR. Spec references are to
SPEC-ipd-core v3 (§) and SPEC-ipd-companions (C§).

### M0 — Ground
- **E0.1 Task engine (`tasks` module, C§2).** Done means: states and escalation ladder per kind; two workers
  accepting one task → exactly one wins; off-shift worker's tasks return to the pool; duplicate request in
  10 min merges; worker phone list at 390 px and supervisor board at 1920 × 1080.
- **E0.2 IPD contracts and intents skeleton (§0B).** Done means: every intent in §0B has a zod contract in
  packages/contracts and a refusal-code list; admission workflow definition validates (no dangling state,
  every branch reaches a terminal); intent idempotency keys tested.
- **E0.3 Hospital in the registry (§4.1).** Done means: spreadsheet loader creates floors, wards, rooms and
  beds with class, gender rule, isolation type, ICU flag, equipment; loader refuses a bed without a class;
  staging holds the whole confirmed bed split.
- **E0.4 Rate card (§2.2).** Done means: incumbent IPD tariff imported line by line; go-live check lists any
  class missing room, nursing or visit rate; owner reviews in the tariff screen.
- **E0.5 Goal queries (§6).** Done means: one named query per goal; each runs in CI on seeded data and returns
  the expected number.

### M1 — Beds and admission
- **E1.1 ipd-beds (§4.1, board A).** Done means: spec §6 bed checks; board fits 1920 × 1080; wall mode hides
  names; incumbent beds shown and released by a tap.
- **E1.2 ipd-admit (§4.2, board B).** Done means: spec §6 admission checks; band prints with allergy in words;
  emergency one-tap admit; downtime paper serials back-fill.
- **E1.3 passes (C§8).** Done means: passes per class; discharge, transfer out, death and absconding expire
  all; lost pass reissue revokes the old one.
- **E1.4 housekeeping (C§3).** Done means: one cleaning task per release; bed unassignable until verified;
  terminal clean needs a supervisor; clocks on board A.
- **E1.5 maintenance (C§9).** Done means: blocked bed stays blocked until ticket closed and nurse confirms;
  3 faults in 30 days flags the item.
- **E1.6 transport (C§6).** Done means: high-score patient task cannot start without an escort; handover by
  wristband scan.
- **E1.7 bmw (C§4), parallel from M0.** Done means: barcode label per bag; department and central weights;
  36 h warning, 48 h alert; 6 % CBWTF gap creates a dispute; monthly and Form IV figures from records.

### M2 — Money
- **E2.1 ipd-charges (§4.3).** Done means: day rule tests (highest class held > 1 h, noon + 2 h grace, transit
  under 1 h free); nightly job idempotent and catches up a missed night; visit posts from the doctor's round
  tap; no doctor surface shows money.
- **E2.2 Payer authorisation and split (§2.5).** Done means: pre-auth approved on day 2 covers day 1; denial
  turns stay to cash with signed consent on file; room-rent cap deduction computed; scheme admissions refuse
  receipts except approved non-covered lines.
- **E2.3 Deposit ladder and bill desk (§4.3, board H).** Done means: 75 % and 90 % alerts once each, never to
  a doctor; bill desk shows exceptions only; daily totals message has no line items.
- **E2.4 linen (C§5).** Done means: par levels per ward; infected linen separate count; weekly loss variance.

### M3 — Transfer, discharge, cutover
- **E3.1 ipd-transfer (§4.4).** Done means: origin bed held until the receiving nurse accepts; 30 min escalation;
  atomic swap; class change takes effect next noon with consent.
- **E3.2 ipd-discharge (§4.7, board F).** Done means: no completion while a department has not confirmed;
  structured summary template (AI drafter comes in M5); dues path discharges without detention; LAMA,
  absconded, death and transfer-out branches each tested; minimal mortuary register.
- **E3.3 ipd-family (board G).** Done means: OTP to the registered phone only; off for sensitive admissions;
  stops at death and absconding; clinical questions become callback requests.
- **E3.4 Rehearsal and cutover.** Done means: rehearsal week script run with real staff (M3 gate); cutover
  runbook (who, when, rollback); first 48 h war-room log; G1 measuring.

### M4 — Clinical record, ward by ward
- **E4.1 ipd-nursing (§4.5, boards C, D1).** Done means: assessment within 1 h alert; NEWS2 / MEOWS / PEWS by
  patient type; one alert per breach; offline queue for vitals only; night mode; text at 130 % at 390 px.
- **E4.2 ipd-rounds (§4.5A, board E).** Done means: inpatient list incl. boarded patients; one chargeable
  visit per consultant per day; resident entries need co-sign; fit-for-discharge starts the cascade.
- **E4.3 ipd-emar (§4.6, board D2).** Done means: patient labels for every issued unit; no give without both
  scans or a reasoned override; high-alert second PIN; PRN interval enforced; allergy added later re-checks.
- **E4.4 diet (C§7).** Done means: NPO or OT booking removes the patient from the next meal list; transfer
  after printing updates the list and tells the old ward.
- **E4.5 Ward rollout.** Done means: pilot ward gate (M4) passed; each later ward has a dated go-live and a
  2-week G6/G7 record; ICU last.

### M5 — Copilot and agents
- **E5.1 Now cards** (desk providers). Done means: each card type has a provider and permission; stable
  patients make no card.
- **E5.2 Bed Flow.** Done means: proposals only from rule-valid beds; stale proposals withdraw; acceptance
  and override rates logged per week.
- **E5.3 "Since yesterday".** Done means: every line has a source; a number that differs from its record fails
  CI; model down shows the plain timeline.
- **E5.4 SBAR and discharge drafter (T2).** Done means: provenance stamps on every draft; medicines in a draft
  without an active order are flagged; signed copy names the person.

## 5. How the work runs (DECIDED, standard practice)

- One lane per epic; IPD core lanes in series (they touch patients, billing, tariff); companion lanes
  (tasks, bmw, housekeeping, linen, transport, diet, passes, maintenance) in parallel.
- Every lane: spec section → failing acceptance test → build → staging → owner walk against the board → "OK for
  production" → merge outside OPD hours.
- Each epic is a GitHub issue under milestone "IPD core" with `Refs #712`; PRs say `Closes #<epic>`.
- Weekly: goal ledger update (§6) and a one-line status to the owner.
